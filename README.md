## Project Description
A simple 2D game that demonstrate Arc Tangents, Detection Cone, and Dot product.

The player must navigate through a level filled with three types of turrets: **Flame, Sniper, and Shotgun**. Each turret has a unique detection range and attack behavior, with **LineRenderers** showing their danger zones.
The player must avoid turret projectiles and reach the green zone. Getting hit restarts the level, while reaching the green zone it displays a **Win UI**.
